# E-Shop Manager

Навчальний консольний проєкт для дисципліни «Професійний Python» (Лабораторна робота №1, Варіант 3).

## Опис
Система обліку та управління товарами інтернет-магазину. Дозволяє додавати товари, шукати, фільтрувати за категоріями, знаходити найдорожчий товар та розраховувати сумарну вартість залишків.

## Вимоги
- Python 3.11+

## Встановлення
1. Створення та активація віртуального середовища:
```bash
python -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# .venv\Scripts\activate   # Для Windows
